## How to Run This Notebook

You can run this notebook using any of the methods below. **Method 1 (the Colab 
badge) is the easiest and recommended option** — it needs nothing installed and 
works on any device with a browser and a free Google account.

### Method 1: Click the "Open in Colab" badge (Recommended)

1. Click the green **"Open in Colab"** badge at the top of this notebook's page.
2. The notebook opens directly in Google Colab, ready to run.
3. Go to **Runtime → Run all** (or run each cell one by one, top to bottom).
4. A copy is automatically saved to your own Google Drive — you can freely edit, 
   experiment, or make mistakes without affecting the original notebook.

### Method 2: Open manually via Colab's GitHub tab

1. Go to [colab.research.google.com](https://colab.research.google.com).
2. Click **File → Open notebook**.
3. Click the **GitHub** tab.
4. Paste this repository's URL (`drpharmacy/pharma-ml-projects`) or search for it, 
   then select the notebook you want to open.
5. Use this method if the badge link isn't working for any reason.

### Method 3: Download the notebook and upload it yourself

1. Click on the notebook file in this GitHub repository.
2. Click the **download icon** to save the `.ipynb` file to your computer.
3. Go to [colab.research.google.com](https://colab.research.google.com).
4. Click **File → Upload notebook**, then select the downloaded file.
5. This gives you a fully independent copy, not connected to GitHub anymore.

### Method 4: Run it on your own computer (no Google account needed)

1. Install **Jupyter Notebook** or **JupyterLab** on your computer (for example, via 
   Anaconda, or by running `pip install jupyter`).
2. Download the `.ipynb` file from this repository (see Method 3, steps 1–2).
3. Open it in Jupyter on your own computer — this works fully offline.
4. Note: you will need to separately install the required libraries yourself 
   (RDKit, scikit-learn, pandas, etc.), which takes more setup effort than Colab.

### Method 5: Just view the notebook (no running, no account needed)

1. Click on the notebook file directly in this GitHub repository.
2. GitHub will display all the code, explanations, and saved results right in your 
   browser.
3. This is read-only — you can look through everything, but you cannot run or edit 
   the code this way. Useful for quickly checking the content before deciding to 
   run it yourself.
